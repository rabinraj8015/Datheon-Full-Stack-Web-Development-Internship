# Task 2 - Task Manager Application

A responsive task management application built using HTML, CSS, and JavaScript.

## Features
- Add, view, edit, and delete tasks
- Work, Personal, and Study categories
- Due dates
- All, Active, and Completed filters
- Search tasks
- LocalStorage persistence
- Responsive design and completion animation

## Technologies
- HTML5
- CSS3
- JavaScript ES6+
- DOM Manipulation
- LocalStorage
